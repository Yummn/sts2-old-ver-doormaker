# 旧版门扉 / Old Ver. Doormaker

将早期版本的“门扉 / 造门者”Boss 战恢复到《杀戮尖塔 2》。

## 来源与署名

- 原模组：`Old Ver. Doormaker`
- 原作者：`noname`
- v0.103.2 修复与 v0.110.1 兼容改造：Yummn / Codex 协作维护

本仓库保留原作者署名。v110.1 版本依据原模组行为进行兼容重建，不声称拥有游戏原始美术、音频或文本资源。

## v1.1.0

v0.110.1 已移除核心 `DoormakerBoss` 遭遇模型，因此新版不能只重新编译旧 DLL。本版本将旧 Boss 遭遇改为模组内自包含模型，并：

- 重新加入荣耀角色的 Boss 发现顺序与候选池；
- 适配受保护模型 API；
- 适配 `PlayerChoiceContext` 能力指令；
- 适配阶段力量变化与备用站位；
- 将缺失的历史记录图标回退到现有门扉资源，避免资源加载错误。

REDMI K80 Pro / Android v0.110.1 实机启动验证：4/4 Harmony 补丁成功，无补丁失败与接口/资源错误。

## 兼容版本

- Android v0.103.2：使用文件名含“手机-v103”的历史包。
- PC v0.107.1：使用文件名含“电脑-v107.1”的 v1.1.0 包。
- Android v0.110.1：使用文件名含“手机-v110.1”的 v1.1.0 包。

两个版本的 DLL 不可混用。

## 安装

下载 Release 中与游戏版本一致的 ZIP。启动器可直接导入完整 ZIP；手动安装时，将 ZIP 内的模组文件夹完整复制到游戏 `mods` 目录。
