# 旧版门扉（Old Ver. Doormaker）

这个项目把早期版本中的“门扉 / 造门者”Boss 战带回《杀戮尖塔 2》。我维护的是原 MOD 的兼容版本，重点是让它能在目前常见的手机和 PC 游戏版本中继续运行。

## 来源与署名

- 原 MOD：`Old Ver. Doormaker`
- 原作者：`noname`
- v0.103.2 修复及 v0.107.1、v0.110.1 兼容维护：Yummn

仓库保留原作者署名。游戏中的美术、音频和文本仍属于各自权利人；兼容版不声称拥有这些原始资源。

## v1.1.0 做了什么

Android v0.110.1 已经移除核心 `DoormakerBoss` 遭遇模型，因此不能只把旧 DLL 重新编译。v1.1.0 按原 MOD 的行为重建了一个自包含遭遇，并补回荣耀角色的 Boss 发现顺序与候选池，同时适配了受保护模型 API、能力指令、阶段力量变化和备用站位。缺失的历史图标会回退到现有门扉资源，避免加载失败。

该版本在 REDMI K80 Pro / Android v0.110.1 上完成过启动验证，4 个 Harmony 补丁均成功加载。

## 兼容版本

- Android v0.103.2：选择文件名含“手机-v103”的历史包。
- PC v0.107.1：选择文件名含“电脑-v107.1”的 v1.1.0 包。
- Android v0.110.1：选择文件名含“手机-v110.1”的 v1.1.0 包。

从 [GitHub Releases](https://github.com/Yummn/sts2-old-ver-doormaker/releases) 下载对应 ZIP。启动器可以直接导入完整 ZIP；手动安装时，把里面的模组文件夹完整复制到游戏的 `mods` 目录。不同平台的 DLL 不要混用。
